# Projek-Akhir-Embedded-System
Merancang dan mengimplementasikan sistem mitigasi kebakaran dini berbasis ESP32 dengan integrasi sensor Flame IR, MQ-2, dan DS18B20. Mengembangkan mekanisme sensor fusion, indikator peringatan, serta notifikasi real-time melalui Telegram Bot dan MQTT untuk meningkatkan keandalan deteksi dan respons terhadap potensi kebakaran.
